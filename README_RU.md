# Умный калькулятор AI

Готовый Android-проект на Kotlin + Jetpack Compose.

## Что уже подключено

- Русский интерфейс
- Поле для задачи обычным текстом
- POST-запрос к Render API
- Адрес API:
  https://umnyy-calculator-ai-server.onrender.com/v1/calculate
- Результат и объяснение
- История последних расчётов
- Обработка ошибок
- INTERNET permission
- Без хранения AI API ключа в приложении

## Как открыть

1. Распаковать ZIP.
2. Открыть папку `UmnyyCalculatorAI` в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить на телефоне или эмуляторе.
5. Ввести `2 + 2`.
6. Нажать `Рассчитать`.

Важно: ключ AI_API_KEY остаётся только на Render-сервере и не должен помещаться в Android-приложение.
